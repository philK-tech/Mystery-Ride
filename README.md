# Mystery Ride

Ableger von Alienworld: dieselbe prozedurale Bootsfahrt in WebGL2, erweitert um ein Verlies unter dem Schloss (zwischen Nebelwald und Pilzwald) mit animierten Figuren aus „The Ninth Vigil“ (MIT, iamlukethedev).

- Aufbau: `docs/ARCHITEKTUR.md`
- Bauen: `node source/build.mjs`, danach `index.html` im Browser öffnen
- Figuren backen: `source/tools/vigil-bake/README.md`
- Testsprünge: `index.html#t=54`, `#t=54&s=4`, `#figs`
