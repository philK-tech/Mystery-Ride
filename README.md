# Mystery Ride

Ableger von Alienworld: dieselbe prozedurale Bootsfahrt in WebGL2, erweitert um ein Verlies unter dem Schloss (zwischen Nebelwald und Pilzwald) mit prozedural gebauten, animierten Figuren (`source/src/procfig.js`, Szenen in `source/src/vault.js`).

- Aufbau: `docs/ARCHITEKTUR.md`
- Bauen: `node source/build.mjs`, danach `index.html` im Browser öffnen
- Figuren backen: `source/tools/vigil-bake/README.md`
- Testsprünge: `index.html#t=54`, `#t=54&s=4`, `#figs`
